# Security reporting

Do not include private keys, recovery phrases, private recipient information or credentials in issues or pull requests.

Use GitHub's private vulnerability reporting for this repository if the owner has enabled it. If no private channel is available, contact the repository owner before sharing exploit details publicly. No private contact address has been configured in this source.

The interface is unaudited. Transaction writes are currently unavailable and the token deployment is unconfigured. Passing CI is source verification, not a financial or privacy audit.
